# 画面一覧

デザイン参照は `docs/design/`（ブラウザで開ける）。キャプチャは `docs/design/screenshots/`。
データ・権限・フローの詳細は `docs/schema.md` が正。

| ルート | 画面 | デザイン | 認証 |
| --- | --- | --- | --- |
| `/login`, `/signup` | ログイン・新規登録 | `MotoCamp Auth.dc.html` | 不要 |
| `/` | ダッシュボード | `MotoCamp Dashboard.dc.html` | アカウント or ゲスト |

## 共通パーツ

- ヘッダー: ロゴ / 戻る / 通知ベル（未読数バッジ）/ アカウントメニュー
- アバター: イニシャル（表示名の先頭2文字）+ userId から決定的に導く色
- ボタン（primary / secondary / ghost / icon）、タグ、カード、モーダル（Dialog）、入力フィールド、セグメント（S/M/L 等）
- トースト（保存完了、`AlreadyTakenError` など）
- 積載装備メモ入力（テキスト + プリセットタグで追記）

## `/login`, `/signup` — ログイン・新規登録

- タブ切替: ログイン / 新規登録
- 新規登録: 表示名・メール・パスワード・規約同意
- ログイン: メール・パスワード・「お忘れですか？」（パスワードリセット）
- 「招待リンクをお持ちの方はこちら」導線
- Supabase Auth。新規登録時に `User { authUid }` を作成

## `/` — ダッシュボード

- あいさつ（表示名）
- 集計カード（参加中イベント数など。全て導出値）
- イベント一覧: タブ（予定 / 完了 / すべて）、検索（タイトル・場所）
- イベントカード: 日付ボックス、状態タグ（下書き / 準備中 / 完了）、タイトル、場所、期間、メンバーのアバター（最大4 + 残数）、積み込み進捗 `packed / total`
  - 下書き = `DRAFT`、完了 = `endDate < now()`、準備中 = それ以外
- 「イベントを作成」モーダル: イベント名・出発日・帰着日・目的地（任意）、車種（プロフィールへ保存）・積載装備のメモ（このイベントの `EventMember.gearMemo`、初期値はプロフィール）→ 作成者を `OWNER` として `DRAFT` で作成
- アカウントメニュー: プロフィール設定 / ログアウト

## `/events/[eventId]` — イベント詳細（積載管理）

メイン画面。全操作の権限は `docs/schema.md`「権限」。

**ヘッダー**
- タイトル・日程・参加人数・要対応の有無
- 設定ボタン（歯車）→ イベント設定モーダル（下記）
- 下書き時はタイトル下に「下書き」タグと説明
- 通知ベル → このイベントの通知ポップオーバー（ASK はその場で 引き受ける / 断る、すべて既読、「すべての通知を見る」）
- 招待ボタン → 招待モーダル（リンク表示・コピー）
- 追加ボタン → 「何を追加しますか？」（共同装備 / 借りたいギア / 貸せるギア）
- 積み込み表示

**メンバーの積載**
- メンバーカード: アバター、表示名、車種、実効積載装備メモ、担当数
- カードタップで下のリストをそのメンバーで絞り込み
- 「調整が必要なものだけ」フィルタ（= 担当未定 `open` / `unassigned` と、自分宛の `asking`）
- 自分のカード → 積載装備メモ編集モーダル（イベント単位の上書き）

**ギアの貸し借り**
- 「借りたい」リスト（RENTAL）: 状態 `fixed` / `asking` / `open`
  - `open`: 誰でも「自分が貸す」→ 即確定（早い者勝ち）
  - `asking`（自分宛）: 引き受ける / 断る
  - `fixed`（自分が担当）: 積み込み済みトグル、降りる
  - 借り手本人: リクエスト取り下げ（削除）
- 「貸せます（希望者待ち）」リスト（LendableGear）: 他人の登録ギアに「借りたい」→ 宛先付き RENTAL（`asking`）作成。自分の登録は削除可
- 空状態の文言あり

**共同装備の分担**
- SHARED リスト: `fixed` / `unassigned`
  - `unassigned`: 誰でも「自分が運ぶ」→ 即確定
  - 自分が担当: 積み込み済みトグル、降りる
- 空状態の文言あり

**モーダル類**
- アイテムの操作シート: 内容を編集 / 積めないので辞退する（担当者）/ リストから削除（作成者・借り手）
- アイテム編集: ギア名、かさばり具合 S/M/L
- 借りたいギアのリクエスト: ギア名、サイズ、宛先（登録ギアを選ぶ or 指定なしで募集）
- 貸せるギアの登録: ギア名、サイズ

**イベント設定モーダル**（デザインの Tweaks「viewerRole」「eventStatus」で表示を切替）
- オーナー: タブ 基本情報 / メンバー / 招待リンク
  - 基本情報: 公開状態（下書きなら「公開する」）、イベント名・目的地・出発日・帰着日の編集。日程・目的地を変えると保存前に「全員に通知されます」を表示 → SCHEDULE_CHANGED（変えた項目ごと）
  - メンバー: 参加中メンバー一覧（オーナー / あなた タグ）。オーナー以外に「外す」→ その場で影響（担当が募集中に戻る件数・取り消されるリクエスト・貸せるギア）を表示して確認 → 離脱処理
  - 招待リンク: 発行済みリンク一覧（発行日・期限・参加数・有効/無効）、「無効にする」、「新しいリンクを発行」
- メンバー: 「オーナーだけが操作できます」の説明 + 「このイベントから退出する」（影響表示 → 確認 → 退出、ダッシュボードへ）。オーナーは退出不可

## `/notifications` — 通知一覧

- 自分宛の全通知（`recipientId = 自分`）を新しい順。イベント名を併記
- 未読表示、すべて既読にする
- ASK は 引き受ける / 断る（対応済みは `resolvedAt` で無効表示）
- タップで該当イベントへ
- 文面は `type + actor + item + payload` からクライアントで生成。相対時刻

## `/profile` — プロフィール設定

- 集計（参加中のイベント数、走行回数 = 終了済みイベント数。導出）
- 表示名、メールアドレス（Supabase Auth 側）
- バイクと積載装備: 車種、既定の積載装備メモ（イベントのメモの初期値）
- 未保存バー（元に戻す / 変更を保存）、保存トースト
- アカウント: パスワード変更、ログアウト、アカウント削除

## `/j/[token]` — 招待・参加

状態ごとに表示が変わる（デザインでは状態プレビューで切替。実装では自動判定）。

1. ログイン済み: イベント概要 + 「このアカウントで参加する」/「別の名前でゲスト参加」
2. 未ログイン: 参加方法の選択（ログイン / ゲスト参加）
3. ゲスト参加フォーム: 表示名（必須）、車種・積載装備メモ（任意）→ 参加
4. 参加済み: 「◯◯さんとして参加中」+ イベントを開く
5. 無効（期限切れ・失効）: 説明 + ログイン導線

## `/claim` — ゲスト→アカウント引き継ぎ

ゲスト Cookie を持った状態でログイン・登録したときに表示。

1. 引き継ぎ: ゲストの担当装備をアカウントへ（新規登録なら `User.authUid` を紐付け、既存アカウントならメンバー枠の `userId` を付け替え）
2. 統合: そのアカウントが同じイベントに既に参加している場合。手順は `docs/schema.md`「ゲスト → アカウントの引き継ぎ」
3. 無効: 期限切れ・引き継ぎ済み

4. **オーナー移譲** — 初版はなし（オーナーは退出不可）
